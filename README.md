# murus_igneus

Murus Igneus aims to be an open-source Linux-based firewall and UTM platform, designed for advanced network security, routing, VPN, intrusion prevention and AI-assisted management.

**Status: experimental alpha (0.3.0-alpha), not for production.** Today the project contains an IPv4 firewall, static routing, NAT and a web interface with FortiGate backup import. VPN, intrusion prevention/UTM and AI-assisted management are planned and not implemented. See [README-ALPHA.md](README-ALPHA.md) for the actual status and [SOURCE_STATUS.md](SOURCE_STATUS.md) for the completeness of the recovered sources.
