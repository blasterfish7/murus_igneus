# Code provenance

Murus Igneus is derived from application sources recovered from an owner-provided OpenWall 0.2.0 test ISO. Recovery from the installed image may omit original packaging, build infrastructure and test data.

The recovered OpenWall application files have MIT license notices. Preserve their existing notices while reviewing the repository GPLv3 license and any external component obligations. No proprietary Fortinet code, firmware or assets are included. Backup parsing
and configuration translation are independent application code. The Devuan
root is rebuilt from signed main packages, with package provenance recorded
in the ISO. Official ClamAV signature downloads use FreshClam.

See `SOURCE_STATUS.md` for the completeness warning.
